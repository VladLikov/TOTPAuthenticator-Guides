Facebook لاگ اِن کی حفاظت کے لیے مختلف طریقے استعمال کر سکتا ہے: authenticator app، official app میں approval، SMS، passkey یا account confirmation۔ اکاؤنٹ کو TOTP میں صرف اس وقت شامل کریں جب Facebook authenticator app کے لیے QR code یا manual key دکھائے۔

### 1. Facebook کھولیں

App یا website میں sign in کریں۔

### 2. Account settings کھولیں

Profile، account settings، privacy یا security میں جائیں۔

### 3. Sign-in protection تلاش کریں

Two-factor authentication، login verification، two-step verification یا اضافی sign-in methods تلاش کریں۔

### 4. Authenticator app منتخب کریں

اگر یہ option موجود ہو تو اسے منتخب کریں۔

### 5. Code scan کریں یا key درج کریں

TOTP سے QR code scan کریں یا manual key درج کریں۔

### 6. Code confirm کریں

TOTP کا 6-digit code Facebook میں درج کریں۔

### 7. Recovery codes محفوظ کریں

اگر Facebook recovery codes دے تو انہیں محفوظ رکھیں۔ اگر صرف SMS، push approval، passkey یا official app دستیاب ہو تو وہ طریقہ الگ سے استعمال کریں۔
