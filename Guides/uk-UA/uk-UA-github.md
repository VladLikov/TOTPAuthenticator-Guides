GitHub може використовувати різні способи захисту входу: застосунок-автентифікатор, підтвердження в офіційному застосунку, SMS, passkey або підтвердження акаунта. Додавайте акаунт у TOTP лише тоді, коли GitHub показує QR-код або ручний ключ для застосунку-автентифікатора.

### 1. Відкрийте GitHub

Увійдіть у застосунок або на сайт.

### 2. Відкрийте налаштування акаунта

Перейдіть у профіль, налаштування акаунта, приватність або безпеку.

### 3. Знайдіть захист входу

Шукайте двофакторну автентифікацію, підтвердження входу, двоетапну перевірку або додаткові способи входу.

### 4. Виберіть застосунок-автентифікатор

Оберіть цей варіант, якщо він доступний.

### 5. Відскануйте код або введіть ключ

Відскануйте QR-код у TOTP або введіть ручний ключ.

### 6. Підтвердьте код

Введіть 6-значний код із TOTP назад у GitHub.

### 7. Збережіть коди відновлення

Якщо GitHub надає коди відновлення, збережіть їх у безпечному місці. Якщо доступні лише SMS, push-підтвердження, passkeys або офіційний застосунок, використовуйте цей спосіб окремо.
