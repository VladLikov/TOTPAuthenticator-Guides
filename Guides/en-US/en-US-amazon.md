Enabling two-factor authentication (2FA) for your Amazon account provides an additional layer of security.

### 1. Locate 2FA Settings

Log in to Amazon, open the account menu under your profile image, and choose Account.

![Amazon setup step 1](https://phund.s3.amazonaws.com/authen-cms/217bc2eb-b0db-4a63-93ea-a3a1b20b628a.webp)

### 2. Login & Security

Click Login & Security.

![Amazon setup step 2](https://phund.s3.amazonaws.com/authen-cms/8addc8c8-b868-48b0-8076-15bd0bdc8f0e.webp)

### 3. Two-Step Verification Settings

Select Edit next to Two-Step Verification (2SV) Settings.

![Amazon setup step 3](https://phund.s3.amazonaws.com/authen-cms/260bdc54-b8e3-4c1b-b303-9a7e4c6fcbf8.webp)

### 4. Get Started

Review the overview of Two-Step Verification and click Get Started when ready.

![Amazon setup step 4](https://phund.s3.amazonaws.com/authen-cms/0ace6b19-3fb8-46a4-8342-d644b3133ce3.webp)

### 5. TOTP

Choose TOTP as the preferred verification option.

![Amazon setup step 5](https://phund.s3.amazonaws.com/authen-cms/af1c988c-a976-4662-8d56-ffa46a8dcd72.webp)

### 6. Set up Two-Factor Authentication

Keep the QR code page open while you prepare TOTP.

![Amazon setup step 6](https://phund.s3.amazonaws.com/authen-cms/315f4f42-fb68-4d9a-8785-9829908216a9.webp)

### 7. Capture QR Code

Tap + in TOTP and scan the QR code from Amazon (avoid the demo QR).

![Amazon setup step 7](https://phund.s3.amazonaws.com/authen-cms/315f4f42-fb68-4d9a-8785-9829908216a9.webp)

### 8. Verification Code

The app fills the Amazon logo, account name, and setup code automatically, tap Save and adjust the icon if needed.

![Amazon setup step 8](https://phund.s3.amazonaws.com/authen-cms/260bdc54-b8e3-4c1b-b303-9a7e4c6fcbf8.webp)

### 9. Confirm OTP Code

Enter the 6-digit code from TOTP into the Verify OTP field on Amazon.

![Amazon setup step 9](https://phund.s3.amazonaws.com/authen-cms/315f4f42-fb68-4d9a-8785-9829908216a9.webp)

### 10. Two-Step Verification is Enabled

Future sign-ins require the one-time password from TOTP.

![Amazon setup step 10](https://phund.s3.amazonaws.com/authen-cms/315f4f42-fb68-4d9a-8785-9829908216a9.webp)
