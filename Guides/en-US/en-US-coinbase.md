Enabling two-factor authentication (2FA) for your Coinbase account protects your balance and personal data.

### 1. Locate 2FA Settings

Log in to Coinbase, open the Account menu in the top right, and select Settings.

![Coinbase setup step 1](https://phund.s3.amazonaws.com/authen-cms/3330858d-e78f-44b5-b8c3-e743708b86c3.webp)

### 2. Security

Choose the Security tab inside Settings.

![Coinbase setup step 2](https://phund.s3.amazonaws.com/authen-cms/a1ea187b-4c9f-45b8-bb00-59bb720fce1c.webp)

### 3. Other Options

Under Other Options, select Authenticator as your method.

![Coinbase setup step 3](https://phund.s3.amazonaws.com/authen-cms/76843a52-1f4b-47d7-842f-7c8b3b08bd1e.webp)

### 4. Verify Your Phone Number

Enter the seven-digit code that Coinbase sends to your phone and click Confirm.

![Coinbase setup step 4](https://phund.s3.amazonaws.com/authen-cms/b3afc881-ccfe-4e0c-81e4-b4bde0b9e054.webp)

### 5. QR Code

Keep the QR code window open while you prepare TOTP.

![Coinbase setup step 5](https://phund.s3.amazonaws.com/authen-cms/49422ce8-1744-4128-996b-e42085e627ca.webp)

### 6. Capture QR Code

Tap + in TOTP to scan the QR code; import it from Files if scanning is not possible.

![Coinbase setup step 6](https://phund.s3.amazonaws.com/authen-cms/da657545-ee25-4f85-b2a7-17aea839a658.png)

### 7. Two-Factor Authentication Code

The app fills the Coinbase logo, account name, and setup code automatically; tap Save.

### 8. Copy and Verify Your Code

Enter the code from TOTP on the Coinbase website and click Enable.

![Coinbase setup step 8](https://phund.s3.amazonaws.com/authen-cms/ee20d9b5-de40-4786-b260-33f2df61c230.webp)

### 9. Done

![Coinbase setup step 9](https://phund.s3.amazonaws.com/authen-cms/514d6ac0-51c4-4c4c-8d8b-65787333272a.webp)

Two-factor authentication is active, and Coinbase will request TOTP code for sign-ins.
