NY.gov ID supports time-based one-time passwords (TOTP) with an authenticator app. Use this guide only when NY.gov ID shows a QR code or secret key for an authenticator app. SMS, push, passkeys and hardware keys are configured separately.

Source: https://dol.ny.gov/MFA

### 1. Open NY.gov ID

Sign in to NY.gov ID on the official website or app.

### 2. Open account security

Go to account, profile, sign-in, privacy or security settings.

### 3. Choose two-factor authentication

Turn on two-factor authentication and choose the authenticator app option.

### 4. Scan the QR code

Scan the QR code with TOTP or enter the secret key manually.

### 5. Confirm setup

Enter the 6-digit code from TOTP back into NY.gov ID.

### 6. Save recovery codes

Store backup codes or recovery methods somewhere safe.
