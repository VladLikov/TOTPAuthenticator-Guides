GitHub можно настроить в TOTP, если сервис показывает QR-код или код настройки для приложения-аутентификатора. Держите страницу настройки открытой, пока добавляете аккаунт.

### 1. Откройте настройки GitHub

![GitHub setup step 1](https://phund.s3.amazonaws.com/authen-cms/eedd44e8-10df-49cb-bfd6-1d6cc695ccf5.webp)

### 2. Откройте пароль и аутентификацию

![GitHub setup step 2](https://phund.s3.amazonaws.com/authen-cms/bf6e157c-db3c-46bc-a73f-18154ed0c855.webp)

### 3. Настройте двухфакторную защиту

![GitHub setup step 3](https://phund.s3.amazonaws.com/authen-cms/7a48ebf6-5e83-43bb-9264-0117f9d76ce0.webp)

### 4. Выберите приложение-аутентификатор

![GitHub setup step 4](https://phund.s3.amazonaws.com/authen-cms/32f492de-2768-4283-a52a-46815e5ef1df.webp)

### 5. Сканируйте QR-код

Откройте TOTP, нажмите плюс и отсканируйте QR-код. Если сканировать нельзя, введите код настройки вручную.

![GitHub setup step 5](https://phund.s3.amazonaws.com/authen-cms/12873a71-122d-4009-a551-0d980bd05788.png)

### 6. Сохраните аккаунт GitHub

Проверьте название сервиса, сохраните аккаунт и скопируйте текущий одноразовый код.

### 7. Подтвердите код

Введите код, который сервис отправил на текущий способ подтверждения.

![GitHub setup step 7](https://phund.s3.amazonaws.com/authen-cms/b59b56b0-c147-4a40-a26c-13db96820947.webp)

### 8. Скачайте резервные коды

Следуйте подсказкам сервиса на этом шаге. Не закрывайте страницу, пока аккаунт не сохранен в TOTP.

![GitHub setup step 8](https://phund.s3.amazonaws.com/authen-cms/3d7fddd9-282d-48df-8f1b-b5800ce852c9.webp)

### 9. Завершите настройку

Следуйте подсказкам сервиса на этом шаге. Не закрывайте страницу, пока аккаунт не сохранен в TOTP.

![GitHub setup step 9](https://phund.s3.amazonaws.com/authen-cms/8d3245ca-b521-4a15-91b0-0954a39ecad9.webp)

⚠️ Это руководство справочное. TOTP не связан с GitHub; названия продуктов и товарные знаки принадлежат их владельцам.
