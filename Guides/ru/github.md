GitHub поддерживает TOTP-приложения, security keys, passkeys и recovery codes. Для этого приложения нужен вариант **Authenticator app**.

1. Откройте GitHub и перейдите в **Settings**.
2. Выберите **Password and authentication**.
3. В блоке **Two-factor authentication** нажмите настройку 2FA.
4. Выберите **Authenticator app**.
5. Отсканируйте QR-код этим приложением.
6. Введите код из приложения на GitHub.
7. Скачайте или сохраните recovery codes до завершения настройки.

Официальная документация: [Configuring two-factor authentication](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication).
