# Discord: двухфакторная аутентификация

Discord поддерживает authenticator app и backup codes. Для добавления кода нужен QR-код из настроек аккаунта.

1. Откройте Discord.
2. Перейдите в **User Settings**.
3. Откройте **My Account**.
4. В разделе **Multi-Factor Authentication** выберите включение 2FA.
5. Введите пароль аккаунта, если Discord попросит.
6. Отсканируйте QR-код этим приложением.
7. Введите текущий код и сохраните backup codes.

Официальная справка: [Setting up Two-Factor Authentication](https://support.discord.com/hc/en-us/articles/219576828-Setting-up-Two-Factor-Authentication).
