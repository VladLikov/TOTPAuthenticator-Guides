X поддерживает authentication app и security key. SMS 2FA может быть ограничена для части аккаунтов, поэтому приложение-аутентификатор обычно надежнее.

1. Откройте X.
2. Перейдите в **Settings and privacy**.
3. Откройте **Security and account access**.
4. Выберите **Security**.
5. Откройте **Two-factor authentication**.
6. Выберите **Authentication app**.
7. Отсканируйте QR-код этим приложением.
8. Введите код и сохраните backup code.

Официальная справка: [Two-factor authentication](https://help.x.com/en/managing-your-account/two-factor-authentication).
