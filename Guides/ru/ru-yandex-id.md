Яндекс поддерживает вход по паролю и одноразовому коду из Яндекс ID или другого приложения-аутентификатора. Такой аккаунт можно добавить в это приложение, если в настройках показан QR-код или код настройки.

1. Откройте [Безопасность Яндекс ID](https://id.yandex.ru/security).
2. В способах входа выберите **Пароль + одноразовый пароль**.
3. Добавьте аккаунт в приложение для одноразовых паролей.
4. Отсканируйте QR-код этим приложением или введите ключ вручную, если Яндекс его показывает.
5. Подтвердите настройку текущим одноразовым паролем.
6. Проверьте, что у вас сохранены резервные способы восстановления доступа.

Не передавайте одноразовые коды другим людям, даже если они представляются поддержкой.

Официальная справка: [Вход по паролю + одноразовому паролю](https://yandex.ru/support/id/ru/authorization/password-plus-otp.html).
