Web Hosting Canada prend en charge les codes à usage unique TOTP avec une application d'authentification. Utilisez ce guide uniquement si Web Hosting Canada affiche un QR code ou une clé secrète pour une application d'authentification. Les SMS, notifications push, passkeys et clés matérielles se configurent séparément.

Source : https://clients.whc.ca/en/knowledgebase/1430

### 1. Ouvrir Web Hosting Canada

Connectez-vous à Web Hosting Canada depuis le site web ou l'application officielle.

### 2. Ouvrir la sécurité du compte

Accédez aux réglages de compte, de profil, de connexion ou de sécurité.

### 3. Activer la double authentification

Choisissez l'option application d'authentification lorsque Web Hosting Canada la propose.

### 4. Scanner le QR code

Scannez le QR code avec TOTP ou saisissez la clé secrète manuellement.

### 5. Confirmer le code

Saisissez dans Web Hosting Canada le code à 6 chiffres généré par TOTP.

### 6. Conserver les codes de secours

Enregistrez les codes de récupération dans un endroit sûr.
