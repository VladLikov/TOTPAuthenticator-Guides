Bourse Direct prend en charge les codes à usage unique TOTP avec une application d'authentification. Utilisez ce guide uniquement si Bourse Direct affiche un QR code ou une clé secrète pour une application d'authentification. Les SMS, notifications push, passkeys et clés matérielles se configurent séparément.

Source : https://www.boursedirect.fr/fr/support/faq/connexion

### 1. Ouvrir Bourse Direct

Connectez-vous à Bourse Direct depuis le site web ou l'application officielle.

### 2. Ouvrir la sécurité du compte

Accédez aux réglages de compte, de profil, de connexion ou de sécurité.

### 3. Activer la double authentification

Choisissez l'option application d'authentification lorsque Bourse Direct la propose.

### 4. Scanner le QR code

Scannez le QR code avec TOTP ou saisissez la clé secrète manuellement.

### 5. Confirmer le code

Saisissez dans Bourse Direct le code à 6 chiffres généré par TOTP.

### 6. Conserver les codes de secours

Enregistrez les codes de récupération dans un endroit sûr.
