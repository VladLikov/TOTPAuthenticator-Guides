Les sources publiques vérifiées ne confirment pas de configuration TOTP standard avec application d’authentification pour Revolut. Le service peut protéger la connexion par SMS, e-mail, passkey, validation push, jeton matériel ou application officielle. Ajoutez Revolut à TOTP uniquement si un code QR ou une clé de configuration est affiché.

Source : https://www.revolut.com/en-US/help/more/revolut-web-app/accessing-the-retail-web-app

### 1. Ouvrez Revolut

Connectez-vous à l’application ou au site officiel.

### 2. Ouvrez la sécurité du compte

Ouvrez Profil, Compte, Connexion, Confidentialité ou Sécurité.

### 3. Vérifiez les méthodes disponibles

Activez la méthode de protection proposée par le service.

### 4. Ajoutez à TOTP

Scannez le code QR avec TOTP ou saisissez la clé manuellement. Sans QR ni clé, ne créez pas d’entrée TOTP.

### 5. Confirmez la configuration

Saisissez dans Revolut le code à 6 chiffres affiché par TOTP.

### 6. Enregistrez les codes de secours

Conservez les codes de secours ou méthodes de récupération en lieu sûr.
