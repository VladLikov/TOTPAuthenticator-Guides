GitHub 可能使用不同的登录保护方式：身份验证器 App、官方 App 确认、短信、通行密钥或账号确认。只有当 GitHub 显示用于身份验证器 App 的二维码或手动密钥时，才把账号添加到 TOTP。

### 1. 打开 GitHub

在 App 或网站中登录。

### 2. 打开账号设置

进入个人资料、账号设置、隐私或安全设置。

### 3. 查找登录保护

寻找双因素认证、登录验证、两步验证或其他登录方式。

### 4. 选择身份验证器 App

如果有这个选项，请选择它。

### 5. 扫描二维码或输入密钥

用 TOTP 扫描二维码，或输入手动密钥。

### 6. 确认验证码

把 TOTP 中的 6 位验证码输入到 GitHub。

### 7. 保存恢复码

如果 GitHub 提供恢复码，请安全保存。如果只能使用短信、推送确认、通行密钥或官方 App，请单独使用该方式。
