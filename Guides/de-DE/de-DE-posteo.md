Posteo unterstützt zeitbasierte Einmalcodes (TOTP) über eine Authenticator-App. Verwenden Sie diese Anleitung nur, wenn Posteo einen QR-Code oder geheimen Schlüssel für eine Authenticator-App anzeigt. SMS, Push, Passkeys und Hardware-Schlüssel werden separat eingerichtet.

Quelle: https://posteo.de/en/help/what-is-two-factor-authentication-and-how-do-i-set-it-up

### 1. Posteo öffnen

Melden Sie sich bei Posteo im Browser oder in der offiziellen App an.

### 2. Sicherheitseinstellungen öffnen

Öffnen Sie Konto, Profil, Login, Datenschutz oder Sicherheit.

### 3. Zwei-Faktor-Authentifizierung wählen

Aktivieren Sie die Zwei-Faktor-Authentifizierung und wählen Sie die Option für eine Authenticator-App.

### 4. QR-Code scannen

Scannen Sie den QR-Code mit TOTP oder geben Sie den geheimen Schlüssel manuell ein.

### 5. Einrichtung bestätigen

Geben Sie den 6-stelligen Code aus TOTP wieder bei Posteo ein.

### 6. Wiederherstellung sichern

Speichern Sie Backup-Codes oder andere Wiederherstellungsmethoden sicher.
