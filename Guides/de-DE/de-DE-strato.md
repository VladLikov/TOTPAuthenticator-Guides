STRATO unterstützt zeitbasierte Einmalcodes (TOTP) über eine Authenticator-App. Verwenden Sie diese Anleitung nur, wenn STRATO einen QR-Code oder geheimen Schlüssel für eine Authenticator-App anzeigt. SMS, Push, Passkeys und Hardware-Schlüssel werden separat eingerichtet.

Quelle: https://www.strato.de/faq/sicherheit/zwei-faktor-authentifizierung-einstellen/

### 1. STRATO öffnen

Melden Sie sich bei STRATO im Browser oder in der offiziellen App an.

### 2. Sicherheitseinstellungen öffnen

Öffnen Sie Konto, Profil, Login, Datenschutz oder Sicherheit.

### 3. Zwei-Faktor-Authentifizierung wählen

Aktivieren Sie die Zwei-Faktor-Authentifizierung und wählen Sie die Option für eine Authenticator-App.

### 4. QR-Code scannen

Scannen Sie den QR-Code mit TOTP oder geben Sie den geheimen Schlüssel manuell ein.

### 5. Einrichtung bestätigen

Geben Sie den 6-stelligen Code aus TOTP wieder bei STRATO ein.

### 6. Wiederherstellung sichern

Speichern Sie Backup-Codes oder andere Wiederherstellungsmethoden sicher.
