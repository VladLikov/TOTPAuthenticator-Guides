The public sources we checked do not confirm a standard authenticator-app TOTP setup for Paytm. Paytm may protect sign-in with SMS, email, passkeys, push approvals, a hardware token, or its official app. Add it to TOTP only if Paytm shows a QR code or setup key.

Source: https://blog.paytm.com/secure-2-step-authentication-login-on-paytms-website-6dd5a20ae1b2

### 1. Open Paytm

Sign in to the official app or website.

### 2. Open account security

Go to Profile, Account, Login, Privacy, or Security settings.

### 3. Review available protection methods

Enable the method that Paytm offers: SMS, email, push approval, passkey, hardware token, or the official app.

### 4. Look specifically for an authenticator app option

Only a screen with a QR code or setup key can be added to TOTP.

### 5. Add to TOTP only if a QR code appears

Scan the QR code or enter the key, then confirm the 6-digit code in Paytm.

### 6. Save recovery options

Save backup codes or recovery methods if Paytm provides them.
