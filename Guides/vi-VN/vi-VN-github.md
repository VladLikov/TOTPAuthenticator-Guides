GitHub có thể dùng nhiều cách bảo vệ đăng nhập: ứng dụng xác thực, phê duyệt trong ứng dụng chính thức, SMS, passkey hoặc xác nhận tài khoản. Chỉ thêm tài khoản vào TOTP khi GitHub hiển thị mã QR hoặc khóa thủ công cho ứng dụng xác thực.

### 1. Mở GitHub

Đăng nhập trong ứng dụng hoặc trên trang web.

### 2. Mở cài đặt tài khoản

Vào hồ sơ, cài đặt tài khoản, quyền riêng tư hoặc bảo mật.

### 3. Tìm bảo vệ đăng nhập

Tìm xác thực hai yếu tố, xác minh đăng nhập, xác minh hai bước hoặc phương thức đăng nhập bổ sung.

### 4. Chọn ứng dụng xác thực

Chọn tùy chọn này nếu có.

### 5. Quét mã hoặc nhập khóa

Quét mã QR bằng TOTP hoặc nhập khóa thủ công.

### 6. Xác nhận mã

Nhập mã 6 chữ số từ TOTP vào GitHub.

### 7. Lưu mã khôi phục

Nếu GitHub cung cấp mã khôi phục, hãy lưu ở nơi an toàn. Nếu chỉ có SMS, phê duyệt push, passkey hoặc ứng dụng chính thức, hãy dùng phương thức đó riêng.
