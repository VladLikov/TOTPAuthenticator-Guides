The public sources we checked do not confirm a standard authenticator-app TOTP setup for WhatsApp. WhatsApp may protect sign-in with SMS, email, passkeys, push approvals, a hardware token, or its official app. Add it to TOTP only if WhatsApp shows a QR code or setup key.

Source: https://www.whatsapp.com/faq/en/general/26000021

### 1. Open WhatsApp

Sign in to the official app or website.

### 2. Open account security

Go to Profile, Account, Login, Privacy, or Security settings.

### 3. Review available protection methods

Enable the method that WhatsApp offers: SMS, email, push approval, passkey, hardware token, or the official app.

### 4. Look specifically for an authenticator app option

Only a screen with a QR code or setup key can be added to TOTP.

### 5. Add to TOTP only if a QR code appears

Scan the QR code or enter the key, then confirm the 6-digit code in WhatsApp.

### 6. Save recovery options

Save backup codes or recovery methods if WhatsApp provides them.
